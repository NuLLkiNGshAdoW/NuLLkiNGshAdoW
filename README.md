* **SOC Sentinel v2**
  Система мониторинга и реагирования на угрозы в беспроводных сетях. Реализован низкоуровневый перехват IEEE 802.11 трафика, настроена автоматическая блокировка угроз через iptables и выполнено портирование архитектуры на Kali Linux.

* **[Youtube Hub App](https://github.com/NuLLkiNGshAdoW/youtube-hub-app)**
  Веб-приложение для централизованного управления контентом канала. Стек: Next.js, Tailwind CSS, Supabase. Предназначено для оптимизации рабочих процессов и взаимодействия с аудиторией.

* **UltimateCarConstructor**
  Проект симулятора транспортного средства в среде Unity. Разработана физическая модель автомобиля на языке C#, включающая настройку сцепления колес, аэродинамику, расчет эффекта Аккермана, звуковые эффекты и систему турбо-ускорения.
